# Changelog

## 0.1.0 — 2026-11-23

- Extract the working experimental LivePhish provider into a standalone community provider.
- Browse and search artists, shows, studio releases and song performances.
- Import saved albums and playlists while preserving composite track IDs.
- Use subscription-aware AAC/FLAC/ALAC playback and one concurrent MA stream.
- Preserve valid HTTP/HTTPS signed audio URLs inside the server.
- Honor integer and HTTP-date Retry-After responses without shortening long waits.
- Add official template checks, real-MA setup tests and mocked transport regression tests.

- Complete and document source provenance and component attribution.

HAOS functional playback acceptance and catalog submission are pending.
